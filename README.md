#  BestiesBakes

**BestiesBakes** is a modern, elegant, and fully responsive bakery website created for an artisanal bakery based in **Sunnyside, Pretoria, South Africa**. The website combines a warm visual identity with a user-friendly interface to create an inviting digital experience for customers browsing baked goods, learning about the bakery, placing orders, or getting in touch.

Designed with a soft **pink, cream, and gold color palette**, BestiesBakes communicates the warmth and creativity associated with a boutique bakery. The design incorporates refined typography, carefully selected imagery, subtle animations, hover effects, decorative elements, and responsive layouts to provide a polished experience across **desktop, tablet, and mobile devices**.

##  Project Highlights

*  Modern bakery-focused UI design
*  Fully responsive across different screen sizes
*  Product catalog with categories and pricing
*  Dedicated online-style ordering interface
*  Customer testimonials and reviews
*  Bakery story and team information
*  Contact details and Google Maps integration
*  Frequently Asked Questions (FAQ) section
*  Product ratings and customer-focused information
*  Smooth hover and visual animations
*  Decorative floating elements and visual effects
*  Consistent color system using CSS variables
*  Lightweight front-end with no build tools required

## 📄 Website Pages

BestiesBakes consists of **five interconnected pages**, each designed around a specific part of the customer journey.

###  Home — `index.html`

The Home page introduces visitors to the BestiesBakes brand and provides quick access to the bakery's main offerings.

It includes:

* A visually engaging hero section
* Featured bakery imagery
* Welcome/introduction section
* "Today's Special" promotion
* Featured products
* Customer testimonials
* Bakery statistics
* Promotional call-to-action banner
* Navigation links to the remaining pages

The page is designed to immediately communicate the bakery's personality while encouraging visitors to explore the products or place an order.

###  About — `about.html`

The About page provides customers with more information about the bakery and the people behind the brand.

Sections include:

* The BestiesBakes story
* Bakery mission and values
* Team/member profiles
* Brand philosophy
* Quality and customer-service principles
* Awards and achievements
* Additional information about the bakery

This page helps establish a stronger connection between the business and its customers by giving the brand a personal identity.

###  Products — `products.html`

The Products page acts as the bakery's digital product catalog.

Products are organized into categories such as:

* Pastries
*  Cupcakes
*  Celebration Cakes

Each product card contains relevant information such as:

* Product image
* Product name
* Description
* Customer rating
* Price
* Visual interaction effects

The categorized layout makes it easier for customers to browse different types of baked goods and find products that suit their needs.

###  Order — `order.html`

The Order page provides a structured interface for customers to submit bakery orders.

The form includes fields for:

* Customer name
* Contact information
* Product selection
* Quantity
* Pickup or delivery preference
* Additional order information
* Date or scheduling details
* Special requests

A quick price guide is also included to give customers an overview of expected costs.

At its current stage, the order form is a **front-end prototype**. Submitted information is not processed by a server or stored in a database.

###  Contact — `contact.html`

The Contact page gives customers multiple ways to communicate with BestiesBakes.

It includes:

* Bakery address
* Phone number
* Email address
* Business hours
* Google Maps integration
* Contact/message form
* Frequently Asked Questions (FAQ)

The page is structured to make important business information easy to find while providing visitors with a convenient way to ask questions.

##  Design & Branding

BestiesBakes uses a carefully selected visual style to create a sophisticated yet friendly bakery aesthetic.

### Color Palette

The primary design uses soft, warm tones such as:

*  Soft pink — warmth and femininity
*  Cream/white — cleanliness and simplicity
*  Gold — elegance and premium presentation
*  Dark neutral tones — readability and contrast

CSS custom properties are used to centralize the color system, making it easy to update the site's branding without changing individual components throughout the stylesheet.

### Typography

The website uses two complementary Google Fonts:

* **Playfair Display** — used for headings and decorative typography
* **Poppins** — used for body text, navigation, forms, and interface elements

The combination creates a balance between an elegant bakery aesthetic and modern web readability.

### Visual Effects

Several subtle effects are incorporated throughout the website, including:

* Smooth hover transitions
* Card animations
* Image interactions
* Gradient text effects
* Floating decorative emojis
* Button animations
* Custom scrollbar styling
* Responsive navigation and layouts

These effects are intended to enhance the user experience without overwhelming the content.

##  Responsive Design

Responsiveness is an important part of the BestiesBakes design.

CSS media queries are used to adapt the layout for:

*  Mobile phones
*  Tablets
*  Laptops
*  Desktop screens

Elements such as navigation menus, product grids, forms, typography, images, spacing, and content sections adjust according to the available screen size.

The goal is to ensure customers can comfortably browse the bakery website regardless of the device they use.

BestiesBakes provides a strong front-end foundation that can be extended into a fully functional bakery platform.

Potential future improvements include:

* Products

* CSS variables

* Typography and visual hierarchy

##  Conclusion

**BestiesBakes** brings together modern web design, responsive development, and a warm bakery-inspired visual identity to create a professional digital presence for a fictional artisanal bakery.

The project demonstrates how a simple HTML, CSS, and JavaScript stack can be used to build a complete multi-page business website — from showcasing products and telling a brand story to providing ordering and contact interfaces.

With future backend and payment integrations, the current prototype could be developed into a complete online bakery ordering platform.
